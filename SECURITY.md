# Security Policy

## Supported Versions

We release security patches for the following versions of `rev` / `rev-decision`:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `rev`, please do **not** open a public issue. Public issues can expose users to security risks before a fix is released.

Instead, please send a vulnerability report directly to:
📧 **jaswanthsanjay88@gmail.com**

### What to Include in Your Report
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept code to reproduce the issue.
- Details of the environment (OS, Python version, PyTorch version, model weights).
- Any proposed mitigations or patches, if available.

### Disclosure Policy & Timeline
- **Initial Response**: We will acknowledge receipt of your report within **48 hours**.
- **Assessment**: We will evaluate the report and confirm the vulnerability within **5 business days**.
- **Patch Release**: Once a fix is verified, a patch will be released to PyPI and GitHub, and public credit will be given (unless anonymity is requested).
